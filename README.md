# My-custom-3D-apps-
Collection of my apps that use my custom 3D

StereoMirror XR can be used with glasses like xreal or wired to sbs 3d displays and app called second screen can help with it. StereoMirror Anaglyph can work with single app projection when phone allows it or a wired 2d screen along with android force desktop mode is what I used with my red magic with high refresh. The others you can just use  on video elements for sbs or anaglyph and the sbs to anaghlyph variant works on native sbs video and converts it to green/magenta or red/cyan. These all are Pseudo 3d except for sbs to anaghlyph that is native. Larger displays work better for anaghlyph
